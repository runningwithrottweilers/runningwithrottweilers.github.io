NEW · PUBLIC BETA · v0.1.0-17

RWR PACKAGE
INTELLIGENCE

Arch Linux updates, without the guesswork. See what is changing, with package descriptions, security signals from the Arch security tracker and upstream changelogs, then run a real full-system upgrade with Polkit authorization. Built with Rust and GTK4, in English and Polish.

The AppImage contains the application. Real updates need the separate backend package, installed by an administrator with pacman, and stay locked until enabled. A real 93-package upgrade has been tested with the native Arch package; the AppImage + backend combination is new in this beta.
